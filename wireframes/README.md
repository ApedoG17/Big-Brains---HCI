This URL is currently blocked by the Figma login gate. The browser reached the login page instead of the design files, so the wireframes could not be opened or exported from this environment without an authenticated Figma session.

How to save the files:
1. Sign in to Figma in the browser.
2. Open the shared project/folder.
3. Export each wireframe as PNG, SVG, or PDF.
4. Save the exported files in this folder:
   - wireframes/exports/
5. Keep consistent names such as:
   - login-wireframe.png
   - dashboard-wireframe.png
   - mobile-flow.png

This folder is ready for the next design pass and implementation work.
